本目录集中维护《时痕实验室：昨日的我》的四份岗位技术指南。每次任务只选择一个岗位中的一个模块，并同时遵守根目录 `README.md` 的产品范围和验收标准。

## 使用顺序

1. 先阅读根目录 `README.md` 中与任务相关的产品规则。
2. 从对应岗位指南的模块索引中只选择一个模块。
3. 在任务卡中明确允许路径、禁止路径、公共接口、验收条件和验证命令。
4. 若任务跨岗位或需要修改公共契约、`pom.xml`、存档或关卡格式，立即停止并由项目经理拆卡审批。

## 当前公共环境基线

- JDK 17
- Maven Wrapper 3.9.11
- JavaFX Controls 17.0.20
- JUnit Jupiter 5.12.2
- Maven Surefire Plugin 3.5.3

Windows PowerShell 使用 `.\mvnw.cmd`；Linux、macOS 和 GitHub Actions 使用 `./mvnw`。个人 `.idea/`、`target/` 和本机 Maven 缓存不得提交。
