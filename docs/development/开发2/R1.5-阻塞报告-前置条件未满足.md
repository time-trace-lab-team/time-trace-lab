### 给开发 1 的最小补丁规格（纯加法，不破坏现有 4 值用法）

```java
public enum GamePhase {
    BOOT(false), MENU(false), LEVEL_SELECT(false), TUTORIAL(false), READY(false),
    PLAYING(true), PAUSED(false), RESETTING(false), RESULT(false), FAILED(false);

    private final boolean advancesLogic;

    GamePhase(boolean advancesLogic) { this.advancesLogic = advancesLogic; }

    /** 该阶段是否推进逻辑刻（仅 PLAYING 为 true）。 */
    public boolean advancesLogic() { return advancesLogic; }
}
```
