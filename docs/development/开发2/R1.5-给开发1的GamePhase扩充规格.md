## 2. `GamePhase.java` 目标内容（可直接覆盖）

```java
package org.example.timeloop.core;

/**
 * 全项目唯一正式阶段枚举（C1 决策记录 §1）。
 *
 * <p>共 10 个阶段，与 README「游戏状态建议」一致。{@link #advancesLogic()}
 * 冻结“是否推进逻辑刻”的语义：仅 {@link #PLAYING} 为 {@code true}，
 * 其余阶段一律冻结（不推进 {@code roundTick}、不写帧）。</p>
 *
 * <p>新增阶段时必须在此显式声明 {@code advancesLogic} 的取值，
 * 使开发 1 与开发 2 两侧的遍历用例自动覆盖新值，强制显式决策。</p>
 */
public enum GamePhase {

    BOOT(false),
    MENU(false),
    LEVEL_SELECT(false),
    TUTORIAL(false),
    READY(false),
    PLAYING(true),
    PAUSED(false),
    RESETTING(false),
    RESULT(false),
    FAILED(false);

    private final boolean advancesLogic;

    GamePhase(boolean advancesLogic) {
        this.advancesLogic = advancesLogic;
    }

    /** 该阶段是否推进逻辑刻（仅 PLAYING 为 true）。 */
    public boolean advancesLogic() {
        return advancesLogic;
    }
}
```

### 三条硬性约束（开发 2 依赖，缺一不可）

1. **值名与顺序**：严格为 `BOOT / MENU / LEVEL_SELECT / TUTORIAL / READY / PLAYING / PAUSED / RESETTING / RESULT / FAILED`，共 10 个。开发 2 的 `LEGAL` 转移表按这 10 个名字建 10 组边。
2. **方法签名**：`public boolean advancesLogic()`，实例方法，无参。不要写成 `advances()` / `isAdvancing()` / `advancesTick()`——开发 2 侧按 `advancesLogic()` 调用。
3. **取值**：仅 `PLAYING` 为 `true`，其余 9 个全部 `false`。

void onlyPlayingPhase_declaresAdvancesLogic() {
