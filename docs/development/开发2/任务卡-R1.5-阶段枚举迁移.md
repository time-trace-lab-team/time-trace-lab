- ⚠️ 本机已知坑：带斜杠的分支引用在 commit / push 后会**静默丢失**。`git switch -c` 报成功但 `git branch -vv` 看不到时，用 reflog 恢复：

```bash
FULL=$(tail -1 .git/logs/refs/heads/feature/<分支名> | awk '{print $2}')
mkdir -p .git/refs/heads/feature
printf '%s\n' "$FULL" > .git/refs/heads/feature/<分支名>
git rev-parse HEAD
```

- **每次 commit / push 后都要 `git rev-parse HEAD` 复核。**
- 提交信息：`refactor(replay): 迁移 RoundClock 到 core.GamePhase 并删除 RoundPhase`
