**设计原则**：`C3DockController` **不拥有位置、不推进运动**，只依据传入的世界坐标与输入给出决策。这样：
- 能与 C2 的 `PatrolController`（或集成层运动）自由组合；
- **不触碰** `level.model.PathNode` ↔ `core.path.PathNode` 的桥接；
- **不修改** `PatrolController`（避免动 C2）。

## 3. 与 README 一致的关键规则（已由测试固化）

- 只有**新发生的方向按下边沿**能让角色离开；进入时一直按住的旧键不产生边沿 → **不会误离开**（`heldOldKeyDoesNotLeaveDock`）。
- 离开方向必须是该 dock 的**合法出口**，否则保持驻留（`illegalExitDirectionKeepsDocked`）。
- 进入即冻结并只发一次 `DOCK_ENTERED`（`enteringRegionFreezesAndEmitsDockEntered`）。
- E 缓冲 6–10 tick 窗口内有效、过后失效（`interactBufferHoldsForWindowThenExpires`，取 8 tick）。
- 事件使用开发二 `TimelineEvent`，含稳定 `actorId`/`sourceRound`/`mechanismId` 与离开方向、原因，可直接进入 `STABLE_ORDER` 排序。
