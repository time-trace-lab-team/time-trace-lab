### 3.1 C0 · 固定步长时钟

`core/FixedStepClock.java`：

- 纯 Java 60 Hz 时钟
- 只有 `PLAYING` 可推进逻辑刻
- 冻结阶段更新时间基准，不补算暂停时长
- 首帧仅建立时间基准；负或零时间差不制造负 accumulator
- 单帧差值和补算次数都有上限
- `interpolationAlpha()` 始终位于 [0, 1)

## 四、C-PLAYER-MOVE-01 · 四方向受约束移动（历史）

### 4.1 目标

把「自动恒速巡行」改为「按住方向键才移动、松开立即停、转向同刻生效、不自动寻路」。

### 4.2 目标行为

1. **按住方向键才移动**：按住即以 `baseSpeed` 推进；松开立即 `IDLE`
2. **转向同刻生效**：任意时刻改按另一方向立即改向（后续被 P0-B 修正为节点中心提交）
3. **不自动寻路**：删除五级优先级、`defaultExit` 自动行进、死路自动返回
4. **遇阻停下**：前方为内墙/边界墙/关闭门 → `IDLE`
5. **同刻相反方向 → 停止**
6. **受约束**：始终吸附在路径中心线上
7. **玩家主动转向只接受直行或 90°**

### 4.3 代码改动
